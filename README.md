เพิ่มความสามารถในการดักจับข้อผิดพลาดระดับ HTTP (เช่น 404 Not Found, 502 Bad Gateway) จากเดิมที่ดักจับได้เฉพาะปัญหาสัญญาณเน็ตหลุด
